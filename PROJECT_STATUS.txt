## Security Audit & Vulnerabilities
| Severity | Vulnerability | Description & Impact |
|---|---|---|
| CRITICAL | Missing Authentication & Authorization | All endpoints under `/api/v1/` are unauthenticated. Any caller can trigger reconciliation, AI investigation, view financial records, or submit review overrides without credentials or RBAC. |
| HIGH | Insecure CORS Configuration | `CORSMiddleware` configured with `allow_origins=["*"]` and `allow_credentials=True`. Enables cross-origin websites to make requests against internal APIs. |
| HIGH | Unrestricted Financial PII Exposure | Endpoints `/api/v1/payments`, `/api/v1/settlements`, and `/api/v1/review/queue` expose customer names, emails, and transaction amounts without auth or rate limits. |
| MEDIUM | Lack of Rate Limiting | Resource-intensive endpoints (`/api/v1/investigator/run`, `/api/v1/reconciliation/run`) have no rate limiting, creating DoS and resource-exhaustion risk. |
| MEDIUM | Missing Database Migration Framework | Schema relies entirely on `Base.metadata.create_all()` without Alembic migrations, preventing controlled schema evolution and rollbacks. |
| MEDIUM | Duplicate `.env` Files | `.env` exists in root and as a duplicate in `backend/.env`. Increases configuration divergence risk. |
| LOW | Pydantic V1 Deprecation Warnings | Class-based `Config` in schemas produces deprecation warnings on Pydantic 2.x. |
| LOW | Unclosed Database Connections in Tests | Unit/integration test suites trigger `ResourceWarning: unclosed database in <sqlite3.Connection>` during test teardown. |

## Blockers and risks
- External OpenAI account credit balance is exhausted (`credit_balance_exhausted` / HTTP 429). The system safely activates local deterministic fallback without crashing.
- Lack of authentication and wildcard CORS poses a security risk if exposed to public networks.

- Active primary database is Neon Cloud PostgreSQL with connection pooling and keepalives; SQLite file remains as local fallback.
- Vanilla JS dashboard in `backend/static/` is the canonical web UI served directly by FastAPI.
